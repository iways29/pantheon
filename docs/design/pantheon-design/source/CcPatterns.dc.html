Shared patterns

Designed once, used on every Control Center screen. The approval card, agent detail, Pause, Kill, status marks and pulse strip come straight from the Brain.

1. Versioned things

Prompts, charters, judge questions and gates. The live version, the history with a note, any two compared, and a way back.

v12LiveYou, 08:55
v11“Tighter scope”
−Use any news source you can find.
+Prefer the company’s own announcement.
Removed lines are struck through and marked −. Added lines are marked +.

2. Preview before apply

Anything that creates or removes things shows one plain sentence first, then the list.

Creates 3 agents (switched off), updates 1 prompt, switches off 1 routine.
+ Patent watcher, Trend spotter, Paper reader~ Research head system v5− 08:30 Old digest

3. Created switched off

New agents, departments, routines and tools start off. Switching on is its own step, and it says what it unlocks.

Patent watcher Off, new
Switch on Patent watcher? It can spend up to $0.40 a day, use Web search and file facts to the brain after Jev checks them.

4. Change log

Every screen has a History drawer. Each line reads as a sentence, before → after, who, when.

5. Locked rules

Fixed for safety, and they look fixed: a lock, a hatched surface, no control, and one line of reason.

R4 tools always ask. Public or permanent actions need you.
Only a person can pause, kill or decide an approval.
A changed MCP tool stays off until you approve the new definition.

Any setting that spends money shows its budget, today and the last 7 days, right next to it.

9. Where glass goes

Liquid Glass is for controls that float over content, never for the content itself.

Glass: tabs, the section nav, drawers, dialogs, sticky action bars, the brain’s lens. Not glass: lists, forms, tables and text. They sit on flat surfaces. Never glass on glass. A button inside a glass panel uses a flat fill. Needs something behind it. Soft light and the astrolabe rings give it something to bend. Reduce transparency frosts it almost solid; more contrast gives it a solid edge.
