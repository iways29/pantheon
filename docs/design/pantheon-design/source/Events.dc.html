Only events move things

Every glow, thread and bead is caused by one event. Nothing moves for decoration, so a still brain means nothing is happening.

Light fades like memory

A touched neighbourhood glows, then dims over 90 seconds. That keeps the last few minutes of work readable at a glance.

Shape first, colour second

Circle for a fact, diamond for waiting on you, dashed for doubt, square for stopped. Colour confirms each shape but never carries status alone.

Readable at 10,000

Zoomed out, neighbourhoods draw as soft clouds with a count, and single points show only where an event touches them. Drag the dial’s hand to replay the day.
